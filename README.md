# Second Brain Builder

Single-page wizard that reverse-engineers Trevor's second-brain system into a
`BLUEPRINT.md` — one instruction file the user pastes into Claude Code, which
then builds their vault (folders, CLAUDE.md, hot.md, grill engine, routines,
templates).

Built for Erica (Social Impact Administrator, ChildFund Rugby). Private page,
client-side password gate.

## Stack

Nothing. One `index.html`, no build, no dependencies, no backend. Answers live
in `localStorage`; the blueprint is generated client-side.

Design tokens inlined from the Trevor Cardozo design system (colours, type,
spacing, effects). Fonts from Google Fonts.

## Deploy

GitHub Pages, same as the other sites in this account.

1. Repo `Tr3v0r86/brain-builder`, Pages on, branch `main`, folder `/`.
2. `CNAME` in this repo already declares `brain.trevorcardozo.com`.
3. Porkbun DNS for `trevorcardozo.com` — add:

   | Type | Host | Answer |
   |---|---|---|
   | CNAME | `brain` | `tr3v0r86.github.io` |

4. In the repo's Pages settings, set the custom domain to
   `brain.trevorcardozo.com` and tick **Enforce HTTPS** once the cert issues
   (a few minutes).

## Before deploying

Change the password. `index.html`:

```js
const GATE_PASSWORD = "rugby";   // <-- CHANGE ME before deploy
```

It's a curtain, not a lock — visible in page source by design. It keeps the
page off casual eyes and nothing more.

## Editing

Wizard content is plain HTML in `index.html`, one `<section class="step">` per
chapter. Blueprint text is generated by `buildBlueprint()` at the bottom —
edit the `P(...)` lines to change what gets built.
